# 🌐 Network Scanner GUI

A Python-based GUI application to scan networks and detect open ports using Nmap.

## 🚀 Features
- User-friendly graphical interface
- Scan any IP address
- Detect open ports
- Real-time scan results display

## 🛠️ Technologies Used
- Python
- Tkinter
- Nmap

## ▶️ How to Run

1. Install Python  
2. Install Nmap  
3. Install required library:
   pip install python-nmap  
4. Run the program:
   python gui_scanner.py  

## 📌 Usage
- Enter target IP (example: 127.0.0.1)  
- Click on "Scan"  
- View results in the window
